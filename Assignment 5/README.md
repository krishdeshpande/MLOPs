## Objective

To build and deploy a **RESTful API** using **FastAPI** that serves a Machine Learning model for inference. The API exposes endpoints to:
- Check service health
- Retrieve model metadata
- Make real-time predictions using a trained Iris flower classifier

---

## Project Structure

```
Assignment 5/

├── README.md              # This file

├── src/
│   └── train_model.py     # Script to train and save the ML model
└── tests/
    └── test_api.py        # Pytest test suite for all API endpoints
```

---

## ML Model

- **Algorithm**: Logistic Regression (scikit-learn)
- **Dataset**: Iris Dataset (150 samples, 4 features, 3 classes)
- **Classes**: setosa, versicolor, virginica
- **Features**: sepal_length, sepal_width, petal_length, petal_width

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Welcome message |
| GET | `/health` | Health check |
| GET | `/model-info` | Model metadata |
| POST | `/predict` | Predict Iris class |

---

## Setup & Usage

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the Model
```bash
python src/train_model.py
```

### 3. Run the API Server
```bash
uvicorn main:app --reload
```

### 4. Test the API
```bash
pytest tests/test_api.py -v
```

### 5. Example Prediction Request
```bash
curl -X POST "http://127.0.0.1:8000/predict" \
     -H "Content-Type: application/json" \
     -d '{"sepal_length": 5.1, "sepal_width": 3.5, "petal_length": 1.4, "petal_width": 0.2}'
```

### Expected Response
```json
{
  "predicted_class": 0,
  "class_name": "setosa",
  "confidence": 0.97
}
```
