## Objective

This assignment demonstrates **workflow automation using Apache Airflow**. A Directed Acyclic Graph (DAG) is designed to simulate a real-world data pipeline that performs the following steps in a scheduled, automated, and dependency-aware manner:

1. **Extract** – Generate or read sample CSV data and save it to a temporary location.
2. **Validate** – Check the extracted data for missing values and print validation statistics.
3. **Process** – Clean and transform the validated data, then save the processed output.
4. **Report** – Generate a summary report (record count, missing values, pipeline status) and save to a text file.
5. **Notify** – Print a success notification confirming the pipeline completed successfully.

## Setup & Run

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Initialize Airflow

```bash
export AIRFLOW_HOME=~/airflow
airflow db init
airflow users create --username admin --password admin --firstname Krish --lastname Deshpande --role Admin --email krish@example.com
```

### 3. Place DAG

Copy `dags/data_pipeline_dag.py` into your Airflow DAGs folder (default: `~/airflow/dags/`).

### 4. Start Airflow

```bash
airflow webserver --port 8080 &
airflow scheduler &
```

Then open [http://localhost:8080](http://localhost:8080), enable the `data_pipeline_dag`, and trigger it manually or let it run on its daily schedule.
